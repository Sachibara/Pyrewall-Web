WINDOWS DEPLOYMENT

Connect the real enforcement engine

  1. Clone or download Sachibara/Pyrewall-Web on Windows 10/11.
  2. Run install_windows.bat as Administrator.
  3. Open http://127.0.0.1:8765.
  4. Change the default administrator password immediately.
  5. Use the local console for WinDivert, Windows Firewall, ARP discovery, real traffic, backups, and user management.
